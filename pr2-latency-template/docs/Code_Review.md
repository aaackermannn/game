# Ревью кода

Автор: aaackermannn. Формат: саморевью при индивидуальном выполнении работы.

## Замечания и исправления

| № | Замечание | Исправление | Проверка |
|---|---|---|---|
| R1 | При отсутствии Python CMake мог пропустить UDP-тесты и анализ CSV | Python обязателен при BUILD_TESTING=ON | Конфигурация с несуществующим Python завершается ошибкой |
| R2 | Не проверялось отклонение PONG с serverSendTimeUs < serverReceiveTimeUs | Добавлен такой пакет в UDP-тест | Пакет учтён как invalid; измерение остаётся активным до корректного PONG |
| R3 | Не проверялась сохранность CSV при повторном run_id | Добавлен отдельный интеграционный тест | Повторный запуск отклонён; CSV не изменён |

## Проверенные требования

| Область | Результат |
|---|---|
| Формат пакетов | Заголовок 7 байт, PING 15, PONG 31; big-endian |
| Валидация | Тип, версия, длины, границы буфера, endpoint и echoed timestamp |
| Модульность | protocol, telemetry и transport разделены |
| Метрики | RTT, SRTT, min/max/mean/median, jitter и timeout/sent |
| Состояния | received, timeout, late, duplicate, unknown, invalid |
| Учёт потерь | Timeout фиксируется один раз; поздний ответ не отменяет потерю по дедлайну |
| Память | inFlight ограничен; активные записи не вытесняются |
| Время | steady_clock; RTT не зависит от часов сервера |
| Повторные отправки | Отсутствуют; attempts=1 |
| Тесты | Catch2, анализ CSV и 6 UDP-интеграционных сценариев |
| Сборки | Debug и Release; CTest 3/3 |

Сторонний участник ревью не привлекался. В GitVerse результат оформляется как саморевью автора, а не как независимое одобрение.
